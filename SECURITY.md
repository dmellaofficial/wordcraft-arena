# Security Policy

## Supported Versions
We take the security of WordCraft & Grammar Arena seriously. The following versions are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly. **Do not create a public GitHub issue** for security vulnerabilities.

Instead, please report it via one of the following methods:

* **Email:** Send details directly to your primary developer email.
* **Private Discussion:** Open a private security advisory on the GitHub repository if available.

Please include as much of the following information as possible to help us reproduce and fix the issue quickly:
* Type of vulnerability (e.g., authentication flaw, data exposure)
* Step-by-step instructions to reproduce the issue
* Any proof-of-concept or screenshots

We will review your report promptly and work on a fix. Thank you for helping keep WordCraft & Grammar Arena safe for everyone!
